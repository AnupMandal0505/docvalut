How it works

1. Mark — start from every Tag and RepositoryManifest, parse manifest JSON, follow index → child manifests, collect config + layer digests.

2. Sweep — delete Blob rows and files not marked, then unreferenced Manifest rows, honouring the grace period.

Tags use on_delete=PROTECT, so a tagged manifest can never be swept.
